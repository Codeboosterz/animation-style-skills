# Layered illustration style bible

Example: 30-second A Door Opens, music-led fully authored test. Same oversized ivory heads, large eyes, compact hoodies, navy room and amber ending as the hybrid version; no Wan clips in this edit.

Workflow: approved still illustrations → separate eye/mouth/hand layers and clean background/door plates → region-limited deformation and pose/cel swaps → GSAP timing and Three.js texture display/hinge → Hyperframes edit/audio/render.

Demonstrated acting: small expression changes, blinks, local breathing, one knock, hand withdrawal and rigid door opening. This differs from the capsule skill's articulated whole-limb body posing. A full still with a camera zoom is not equivalent to these local animated parts.

Strengths: stable artwork, deterministic replay, efficient reuse, exact prop mechanics. Limits: expression variants require matching art; a long phone hold can feel weak without narration; large limb/head changes need additional poses and registration. The two new facial-layer edits had tool metering unavailable, so the original $0.06 Suno spend was never an all-in cost for the film.

QA lesson: a first eye-mask boundary retained a faint old outline; extending the local mask fixed it. Compare closed-eye frames at full size, not only a contact sheet. Preserve the source face landmarks and surrounding hood edge while repairing a patch.
