# B1 style bible

Example: procrastination, revised version 2, 30s, 12 shots, 1280×720/30fps. The complete approved Fola recording is 24.72s; the remaining time shows continued work and a quiet ending. The first 21-second version had ambiguous laptop placement and messy contours and is not the visual target.

Visual grammar: paper #FDFDFC, ink #282c2c, quiet grey props, small yellow accent #F1CE6C. Modest round head, slim body and limbs; hand-drawn character without uncontrolled wobble. Useful negative space; minimal set detail. Rear master keeps the character in the near foreground and the laptop beyond the hands. Inserts change shot scale without reinventing the room.

Example progression: rear hesitation → blank document → coffee → pencil alignment → productivity video → deliberate click → document → first sentence → timer → typing → work despite mess → quiet payoff. This sequence illustrates causal editing, not a fixed template for all topics.

Motion: anticipation/contact/settle for each hand action; natural irregular typing; the body relaxes once work begins. A still-camera hold can carry acting. No constant global pan/zoom. Captions are short semantic lines aligned to actual speech and separated from the action-safe area.

Sound: soft ceramic, pencil, click and key cues at visible contacts, quiet room tone. Fola at native speed. No timer ring before two minutes have elapsed. No compulsory music swell.

Reuse: shared set and prop anchors make inserts repeatable. Keep a pose library for typing, cup grip, pointing and relaxed hands. The portable drawing module retains original geometry but excludes proprietary system fonts and the old renderer. The archived MP4 remains the approved visual evidence; a new font or resolution needs review.
