# Directing a generated historical shot

Specify: source-supported story purpose; reviewed start image/cast; locked camera and screen direction; prop geometry/contact anchors; one permitted action in ordered phases; exact end pose/hold; stationary objects; excluded extra gestures/cuts. Include the complete drawing anchor and relevant cast description in each standalone prompt. Do not assume a later model call has the earlier conversation.

For a book: define cover hinge, fixed base, hand ownership and the one-way closing path. Prefer an authored hinge when the action must be exact. A pair of open/closed reference images constrains endpoints, not every intermediate pose. Review the entire motion, especially rigid cover shape and post-closure hands.

Do not fabricate sources, historical portraits, ethnic insignia, geography or written documents. Generated text can be blank, with verified labels placed later in Hyperframes. New Wan/Omni jobs require current schemas and a bounded generation plan; these instructions are not a submission script.
