# Shared production contract

Read the user's current brief and existing approvals first. A style selects visual grammar and a workflow; it does not select a new story, authorize publication or paid retries, or override a later user instruction. Keep the requested stage: script, storyboard, motion proof or finished preview. Reuse valid approvals instead of asking again.

Hyperframes is the master editor, scene timeline, audio compositor and final export path for future films. Load the installed Hyperframes skill when authoring its compositions. GSAP controls seekable animation; JavaScript defines rigs; Three.js handles rigid objects or the 2D drawing plane where useful. Framer Motion is optional and must use the same film clock. A slide alone does not require Three.js. The bundled examples are editable starting points, not evidence that arbitrary long films can be automated.

Keep one scene per composition, explicit durations and paused GSAP timelines registered after setup. Drive external drawing from `hf-seek`; no independent animation loop or wall-clock physics. Preview custom animation and obtain approval at the requested review gate; a request to create a review video authorizes rendering that preview. Use Hyperframes check, snapshots at relevant action phases and encoded-output inspection. Report exactly what was tested and what needs human listening.

Suno via Kie supplies music; licensed/owned or verified generated Foley supplies sound effects. Gemini 3.8 Flash TTS / Fola supplies optional requested speech, not general music or Foley. Preserve an already-approved recording at its native pace. Music-led visual stories are the default for new films unless the brief calls for narration; B1 and history often benefit from explicit narration. The archived Fola examples remain intact.

Wan 3.0 is the selected generated-video route. Gemini Omni is reserved for appropriate complex/specialized shots; no map animation was produced in this collection. Verify current availability, documentation and price before submitting paid work. Load credentials from a local environment; never copy them into browser files, receipts or repository commits. Save submission receipts and avoid duplicate unknown-state submissions. A failed job is not permission for unlimited retries.

Seedance Mini is retired indefinitely by explicit user choice. Do not submit new jobs or use it as fallback. A5's legacy example and the ledger comparison document historical outputs only; they are not runnable production recipes.

Record actual charges separately from reuse, estimated fresh-generation equivalents, image metering, coding/rigging time and subscriptions. A local re-render spending zero provider credits is not a claim of zero total production cost. Do not quote old account balances as live balances.

For every shot: define camera, screen direction, allowed action, fixed elements, prop contacts and ending pose. A strong prompt cannot guarantee rigid physics. Use authored motion for exact hinges or contacts when generator motion remains unreliable. Review start/contact/extreme/release/rest frames, plus transitions. Preserve artwork, anatomy and staging when changing engines.
