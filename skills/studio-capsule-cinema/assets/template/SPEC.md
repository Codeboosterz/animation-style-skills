# Production specification
1920×1080, 30 fps, exactly 900 frames. Six compositions; Hyperframes master edit and render. Native Canvas 2D geometry on a Three.js orthographic texture plane. GSAP paused timelines, deterministic per-time poses.

Palette: ground #080d0d, room #0b1010, props #202430, outlines #626770, cream #e5e1ca, facial ink #303635, shadow edge #bd396f, dawn #c17b4d. Character head 68×80 local units; body about 210 units tall, approximately 3 heads. Limb width 14–20 units, drawing outline 2.3 units at rig scale; major set contours 3 pixels. Rounded capsule shapes, dot eyes, brows, restrained mouth. No hair until the ending hood; no oversized thumbnail-cartoon eyes.

Safe text at y=170, centered, 46–52px handwritten font. Set floor at y=855, scene content mostly x=360–1600. Scale varies intentionally by shot (wide bed, medium mirror/drawer, wider roof). Each character action has a hold before/after. No constant idle bob.

BANNED: glossy 3D characters, photorealism, title-card montage, generic icon people, hair/large eyes from old brothers film, limb stretch to hit contacts, moving props without hand contact, camera wobble, gradient text, decorative particle fills, source soundtrack reuse.

Approved task stage: an animated recreation preview. Not a final production master approved for publishing. Custom rig motions are presented for review through this preview.
